# Reader's Guide — awesome-selfhosted

## What this project is

**Awesome Selfhosted** is the catalogue of **free software you can run on
your own servers** instead of renting a SaaS product — network services and
web applications across every common need, from analytics and backups to
email, media, communication and e-commerce. Every main-list entry is free
software; each one names its licence and its anti-features (if any) up front.

## How the content is organised

- [`README.md`](README.md) — the list (this guide was written from its
  section outline and the repository tree; the README is very large). Its
  **Software** section holds the catalogue, split into ~95 category
  sub-sections, including: Analytics, Archiving and Digital Preservation,
  Automation, Backup, Blogging Platforms, Bookmarks and Link Sharing,
  Calendar & Contacts, a large Communication family (email solutions, mail
  agents, webmail, IRC, SIP, social networks, video conferencing, XMPP),
  Content Management Systems, CRM, Database Management, DNS, Document
  Management (incl. e-books and library systems), E-commerce, Federated
  Identity & Authentication, Feed Readers, File Transfer & Synchronization,
  and Games.
  - **List of Licenses** — the licence key for the abbreviations used in
    entries.
  - **Anti-features** — the key to the warning markers entries can carry
    (e.g. non-free dependencies or network services).
  - **External Links** and **Contributing** — related resources and the
    submission rules.
- [`non-free.md`](non-free.md) — the companion list of useful self-hostable
  software that is **not** free software, deliberately kept out of the main
  list.
- `_static/` — images/logos used by the README.

## How to use it

1. Pick your need in the README's **Table of contents** and jump to that
   category under **Software**.
2. Compare entries: each gives a description, the source link, the licence
   and any anti-feature markers — decode them with the two key sections.
3. Check `non-free.md` only if no free option fits; everything there is
   flagged non-free by design.
